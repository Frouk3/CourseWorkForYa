# Розроблення демонстраційного плагіна для керування часовими параметрами об’єктів гри Metal Gear Rising: Revengeance мовою C++ 
## Що це?
Цей проєкт є втіленням зупинки часу без використання сторонніх програм які можуть коперсатись по пам'яті гри<br>
Плагін сам діє як "додаток" до гри, використовуючи сам код гри щоб зробити будь-які зміни в середовище гри<br>
## Як воно працює?
Сама гра по собі не може завантажувати сторонні файли по типу .asi, тому тут потрібно використовувати Ultimate-ASI-Loader щоб завантажити їх в гру, бібліотека від Ultimate-ASI-Loader діє як міст через який всі файли плагіну можуть завантажитись в простір ігрового процесу без заморочення що щось піде не так<br>
Як завантажується бібліотека в простір гри? Перед головним запуском програми через процедуру start оперативна система завантажує всі бібліотеки які застосовані в програмі, до прикладу kernel32.dll(система) або winmm.dll(доповнення), та для того щоб їх завантажити потрібно просто закинути доповнення в корневу папку гри І на тому сама програма все за вас зробить, в загальному Windows буде пробувати завантажувати бібліотеки які створила Microsoft що є в корневій папці гри, якщо не знаходить - пропускає, шукає лише через імена самих бібліотек, звідси появляється причина по якій програма може завантажувати будь-яку бібліотеку, навіть якщо це не рідна
## Компіляція
Для того щоб скомпілювати проєкт, вам знадобиться завантажити [mgr-plugin-sdk](https://github.com/Frouk3/mgr-plugin-sdk/tree/pdb-update) та встановити його, так потрібно встановити з бранчу pdb-update<br>
Після завантаження SDK запустіть install.bat, після цього глобальна змінна %MGR_PLUGIN_SDK% буде доступна
